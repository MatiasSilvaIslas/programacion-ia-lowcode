## Instalación

Con el entorno virtual de la clase activado:

```bash
python -m pip install -r requirements.txt
```

Las notebooks usan el archivo `datos/clima_buenos_aires.csv` como respaldo. La notebook de API también puede consultar datos en línea desde Open-Meteo.

TensorFlow no se incluye en este entorno porque la versión estable utilizada en la planificación no es compatible con Python 3.13. Se trabajará luego en un entorno separado con Python 3.12.
